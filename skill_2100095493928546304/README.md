# 资料库多表看板

用 WorkBuddy 的**资料库**搭一个多表联动的工作台 / 看板页面，并部署上线。

典型成品：一个页面同时管**待办 + 打卡 + 记账**，数据存在资料库的多张表里，页面直接读写，手机上也能用。

---

## 它解决什么问题

WorkBuddy 的资料库能把数据存成表，但当你一次要建**三张表**（待办、习惯打卡、记账）并让一个页面同时读写它们时，会撞上一批平台校验规则——报错代码长得像 `DSDK002`、`DSDK003`、`R10`，但搜索引擎上基本查不到。

这个技能就是这批坑的**实测解法合集**：

| 你会遇到的报错 | 本技能给出的解法 |
|---|---|
| `DSDK002` | 每张表写独立函数、`databaseId` 写字面量，而不是通用封装 |
| `DSDK003` / `DSDK006` / `DSDK009` | 多表字段名取并集，生成合并 schema 再跑校验 |
| `R10` | 选择器类名必须在真实 HTML 标记里存在，附隐藏模板块的写法 |
| `DSDK008` | 含 `addRecord` 必须补齐 localStorage 三件套 |
| `DSDK011` / `DSDK012` | 数据绑定属性的正确写法与常见误报区 |

## 适用场景

- 个人工作台：待办 + 打卡 + 记账 + 看板，一个页面全管
- 运营看板：多张业务表汇总到一个可视化页面
- 各类台账：需要 ≥2 张表联动读写的任何 HTML 页面

**只有一张表**的话，直接用内置资料库能力即可，不需要这个技能。
